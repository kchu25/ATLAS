You bring (sequence, value) pairs — DNA or RNA each paired with a measurement.

ATLAS finds which motifs must co-occur to drive the expression, i.e. the combinations of patterns that matter together, not in isolation.

01 — Input

A CSV is all you need

Two comma-separated columns: the sequence and its measured expression value. That's the whole input format.

02 — Usage

Apply it to a sequence-to-expression dataset

One function does everything: it trains a model on your data and writes the motif reports. You need a CUDA-capable GPU to train.

using Pkg
Pkg.add("MotifInference")

# A CUDA-capable GPU is required for training.
# data.csv — two columns (sequence, expression), one row per sequence
sequence,expression
GATCACAGGTCTATCACCCTATTAACCACTCACGGGAGCTCTCCATGCATT,1.5
TTGACAGCTAGCTCAGTCCTAGGTATTATGCTAGCTACTAGAGAAAGAGGA,2.0
CGTACGATCGATCGTAGCTAGCTAGCATCGATCGATCGTACGTAGCATCGA,-0.5

using MotifInference

# That's the whole pipeline: load, tune, train, attribute, render.
run_method("/path/to/mydata.csv")
# Results (trained model, motif caches, HTML reports) are written to a folder
# named after the CSV, under save_root (the current directory by default):
#   run_method("data/mydata.csv")  ->  ./mydata/

# choose the parent directory
run_method("data/mydata.csv"; save_root="/path/to/results")   # -> /path/to/results/mydata/

# choose the folder name explicitly
run_method("data/mydata.csv"; save_folder_name="run01")        # -> ./run01/
using MotifInference

# RNA sequences, fixed seed (skips hyperparameter tuning)
run_method("/path/to/mydata.csv"; seq_type=:rna, seed=42)
