MotifInference.jl learns a neural network that predicts a measured signal from DNA, RNA, or protein sequence — then reads motifs back out of the trained model via game-theoretic attribution, rather than off the raw weights.

00 — Overview

Motifs read out of the model, not the weights

Many sequence analysis methods inspect a model's filters directly to find motifs. MotifInference.jl takes a different route: it first trains a sequence-to-measurement network to predict the experimental signal, then quantifies how much each detected motif — and each combination of motifs — contributes to the prediction using Banzhaf indices from cooperative game theory. The result is a set of filtered singleton motifs together with higher-order interaction terms, rendered as self-contained HTML reports.

01 — Method

A three-stage pipeline

From raw sequence/label pairs to interpretable motif reports.

MODEL
Seq → signal network
→
ATTRIBUTE
Banzhaf indices
→
RENDER
HTML motif reports
STAGE 01

Model

A base layer of learnable PWMs for primary motif detection, hierarchical convolutional layers, and an EfficientNet-style backbone of MBConv blocks with squeeze-and-excitation, ending in a linear output head. Architecture hyperparameters are tuned automatically when no seed is given.

STAGE 02

Motif attribution

The contribution of each detected motif and of multi-motif combinations is quantified with Banzhaf indices via BanzhafInference. Significance is assessed against random-coalition backgrounds, yielding filtered singletons and higher-order interaction terms.

STAGE 03

Rendering

Results are written as HTML motif reports — sequence logos, contribution tables, and interaction summaries — via GlyphEctoplasm, under save_root/<dataset>/.

02 — Features

Flexible inputs, automatic tuning

01

DNA · RNA · Protein

Works across nucleotide and amino-acid alphabets. Set seq_type to :dna, :rna, or :protein — with a mutation model for protein mutagenesis.

02

No file required

Feed a .jld2 dataset, a small CSV of sequence,label, or in-memory strings and labels. All paths construct the same dataset and run the same pipeline.

03

Interaction terms

Beyond single motifs, it scores combinations of sizes [2,3,4,5] to surface higher-order motif interactions.

04

Automatic tuning

Omit seed and architecture hyperparameters are sampled and tuned for you; supply one for a fully reproducible run.

03 — Usage

One entry point: run_method

It runs the full pipeline — load → optional tune → train → attribute → render. A CUDA-capable GPU is required for training.

using Pkg
Pkg.activate(".")
Pkg.instantiate()

# Depends on unregistered packages referenced by local path in Project.toml:
#   BanzhafInference, GlyphEctoplasm,
#   AutoComputationalGraphTuning, SEQ2EXPdata
# These must exist at the expected paths before instantiating.
using MotifInference

# Simplest — point at a .jld2 dataset. With no seed, hyperparameters are tuned.
run_method("/path/to/mydata.jld2")

# With overrides
run_method("/path/to/mydata.jld2"; seq_type=:rna, seed=42)

# Multi-output data — process only a subset of targets
run_method("/path/to/mydata.jld2"; seq_type=:rna, seed=42, output_indices=1:5)
using MotifInference

strings = ["ACGTACGT", "TTGGCCAA", "GGGGCCCC", "AAAATTTT"]
labels  = [1.0, 2.0, 3.0, 4.0]   # one scalar per sequence

# nucleotides
run_method(strings, labels)
run_method(strings, labels; seq_type=:rna, seed=42)

# amino acids for mutagenesis
run_method(aa_strings, aa_labels; seq_type=:protein, type=:mut, GET_CONSENSUS=true)

# Or a CSV of  sequence,label  (header auto-detected, blank lines ignored)
run_method("/path/to/mydata.csv"; seq_type=:rna, seed=42)
using MotifInference

# Build a run configuration explicitly to inspect or reuse it
trc = make_trc("/path/to/mydata.jld2"; seq_type=:dna, seed=42, motif_sizes=[2,3,4])
run_method(trc)

# Batch over several registered datasets
run_all(load_datasets("ecoli", "yeast"))
run_all(load_datasets())   # everything
